# LACToS: Local Anomaly Detection via Conditional Typicality of Superpixels

Code for the paper *LACToS: Local Anomaly Detection via Conditional Typicality of Superpixels*
(under review at ICLR 2027).

LACToS localises anomalies: spatially confined out-of-distribution regions inside an otherwise
in-distribution image. For every small region of a test image it asks whether that region is
*typical* of what a diffusion model trained on in-distribution images expects there, given the
rest of the image. Two ideas make this test tractable: pixels are grouped into superpixels, and
the per-superpixel inpainting posterior is replaced by one denoising posterior shared by all
superpixels. The method needs only an unconditional diffusion model of the in-distribution data
and a posterior sampler.

This repository contains

* the implementation of LACToS (`evaluate.py`, `ood/`),
* the diffusion posterior samplers that draw the reconstructions it scores (`sampling/`),
* inference code for the six baselines of the paper (`baselines/`),
* the evaluation code and the scripts that regenerate the paper's main results (`scripts/`),
* trained checkpoints, test data and reconstructions as a separate download (the asset bundle).

## Method

```
test image x*
   |  1. posterior sampling    y_m = x* + n_m,  n_m ~ N(0, sigma^2 I),   x_m ~ p(x | y_m)   (m = 1..M, DPS)
   v
M reconstructions x_1 .. x_M
   |  2. features              pretrained ResNet-101 (1792-d per pixel) -> per-dataset autoencoder -> 3-d
   v
intensity + feature value at every pixel of x* and of each x_m
   |  3. superpixels           marker-controlled watershed of x* at a target size
   |  4. typicality            per superpixel: histograms over the reconstructions; score of x* = NLL - entropy
   v
superpixel score map  -- 5. spatial Gaussian smoothing -->  pixel-level anomaly map
```

1. **Posterior sampling.** M reconstructions of the test image are drawn with diffusion posterior
   sampling (DPS) under the identity forward model with Gaussian noise, using an unconditional
   diffusion model trained on in-distribution images.
2. **Features.** The image and every reconstruction pass through a pretrained ResNet-101; the
   multi-scale activations are compressed to three dimensions per pixel by an autoencoder trained
   on the in-distribution data.
3. **Superpixels.** The test image is partitioned into superpixels of a chosen average size.
4. **Typicality.** For each superpixel, the intensity values and the feature values of all
   reconstruction pixels form two histograms. The score of the superpixel is the average negative
   log-likelihood of the test image's pixels under a histogram minus the histogram's entropy; the
   intensity term and λ times the feature term are added.
5. **Smoothing.** The superpixel scores are smoothed with a spatial Gaussian into the anomaly map.

| Step | Code |
|---|---|
| 1 | `sampling/dps/sample_fast.py` (CHAOS, DVXray), `sampling/generate_recons.py` (FFHQ), run by `scripts/sample_*.sh` |
| 2 | `ood/embeddings.py`, `PixelAutoEncoder` in `evaluate.py` |
| 3 | `ood/superpixels.py` |
| 4 | `ood/scoring.py` |
| 2–4 for a set of images | `evaluate.py`, run by `scripts/score_lactos.sh` |
| 5 and the metrics | `scripts/make_table1.py`, `full_metric_table.py` |

## Main results

Pooled pixel-level AUROC / AP / AUPRO on three local-anomaly benchmarks: CHAOS (abdominal CT with
synthetic tumours), FFHQ (faces with prosthetics or atypical features) and DVXray (baggage X-ray,
scissors). This is Table 1 of the paper.

|---|---|---:|---:|---:|---:|---:|---:|---:|
| CHAOS | AUROC | 0.9297 | 0.7464 | 0.3786 | 0.6664 | 0.8318 | **0.9707** | 0.9620 |
| | AP | 0.0590 | 0.0193 | 0.0051 | 0.0105 | 0.0410 | 0.3159 | **0.4318** |
| | AUPRO | 0.6811 | 0.4191 | 0.0332 | 0.2513 | 0.5530 | 0.8676 | **0.8764** |
| FFHQ | AUROC | 0.8491 | 0.7162 | 0.7647 | 0.6200 | 0.6707 | 0.7469 | **0.8515** |
| | AP | 0.0798 | 0.0537 | 0.0772 | 0.0405 | 0.0345 | 0.0563 | **0.1177** |
| | AUPRO | 0.4094 | 0.3174 | 0.4047 | 0.2365 | 0.2440 | 0.3083 | **0.5320** |
| DVXray | AUROC | **0.9640** | 0.9234 | 0.8688 | 0.9184 | 0.8944 | 0.8567 | 0.9607 |

Every number in this table is regenerated by the pipeline below from the reconstructions,

The release covers this benchmark. Training code (diffusion models, autoencoders, baselines) is
not included; the trained checkpoints are in the asset bundle.

conda create -n lactos python=3.10 && conda activate lactos

## Running the pipeline

| Stage | Script | What it does | Needs |
|---|---|---|---|
| 0 | `scripts/check_assets.sh` | checks that the bundle is complete | bundle |
| 1 | `scripts/sample_{ct,xray,ffhq}.sh` | samples the reconstructions with DPS | diffusion models, test images |
| 2 | `scripts/score_lactos.sh` | LACToS scoring → per-image score maps | reconstructions, autoencoders |
| 3 | `scripts/run_baselines.sh` | the six baselines → per-image raw maps | baseline checkpoints, 4 environments |
| 4 | `scripts/make_table1.py` | smoothing, pooled metrics, the result table and its comparison with the paper | stages 2 and 3 |

The bundle already contains the output of stage 1 (`recons/`), so the results can be regenerated
with stages 2 to 4 alone:

```bash
GPU=0 bash scripts/score_lactos.sh                 # or one benchmark: CT | xray | ffhq
GPU=0 bash scripts/run_baselines.sh                # or one benchmark: ffhq | ct | xray
python scripts/make_table1.py                      # --only lactos | --only baselines
```

All scripts take `GPU=<index>`, `OUT=<results dir>` (default `results/`) and
`ASSETS=<bundle dir>`.

### Stage 1: sampling the reconstructions

These commands draw the posterior samples that LACToS scores, i.e. the `recons/` folder of the
bundle. They need only `checkpoints/diffusion/` and `data/`. Each script runs one process per
listed GPU and resumes where it stopped.

```bash
GPUS="0 1 2 3" bash scripts/sample_ct.sh       # CHAOS   200 slices x  5 draws = 1,000 reconstructions
GPUS="0 1 2 3" bash scripts/sample_xray.sh     # DVXray  144 images x 20 draws = 2,880 reconstructions
GPUS="0 1 2 3" bash scripts/sample_ffhq.sh     # FFHQ    100 faces  x 20 seeds = 2,000 reconstructions
#  -> results/recons_mine/results_patches_*/      same directory names and layout as recons/ in the bundle
```

Stage 2 scores them when `RECON_ROOT` points at that folder:

```bash
RECON_ROOT=results/recons_mine GPU=0 bash scripts/score_lactos.sh
python scripts/make_table1.py --only lactos
```

Sampler settings and output layout: `sampling/README.md`.

### Stage 2: LACToS scoring

`scripts/score_lactos.sh` runs `evaluate.py` on every image set with the hyperparameters of
the paper and writes one file per test image,
`results/lactos_maps/<benchmark>/<setting>/<set>/samples_<id>.npz`, holding the unsmoothed score
map (`delta_map`), the ground-truth mask and the valid-pixel mask. For FFHQ it runs twice, with
and without the feature term, so that stage 4 can weight the two terms.

### Stage 3: baselines

`scripts/run_baselines.sh` runs PatchCore, SimpleNet, SuperSimpleNet, EfficientAD, GLASS and
DDAD with the checkpoints of the bundle and writes
`results/baseline_maps/<benchmark>/<method>/<setting>/<set>__<id>.npz`.

It needs the official implementations of PatchCore, SimpleNet, GLASS and SuperSimpleNet
(`bash scripts/fetch_third_party.sh` clones them at the commits we used) and their environments
(`environment/patchcore.txt`, `simplenet.txt` — also used for GLASS —, `ssn_env.txt`). DDAD and
EfficientAD run in the interpreter that runs the script (your `lactos` env); point the script at
the other three with `PY_PATCHCORE=... PY_SIMPLENET=... PY_SSN=...` or
`CONDA_ENVS=/path/to/conda/envs` (the env names `patchcore`, `simplenet`, `ssn_env`).

### Stage 4: evaluation

`scripts/make_table1.py` weights the intensity and feature terms, smooths every map, pools the
pixels of each benchmark and computes the metrics. It writes `results/table1.{json,md,tex}` and
prints the comparison with the paper's numbers.

## Evaluation protocol and hyperparameters

* **Metrics** (`full_metric_table.py`, used identically for every method): all valid pixels
  of all test images of a benchmark are pooled; AUROC and AP over that pool; AUPRO is the
  area under the per-region-overlap curve up to FPR 0.3, normalised by 0.3. Anomalous and
  anomaly-free images are pooled together (CHAOS 100 + 100 slices, FFHQ 50 + 50 faces, DVXray
  72 + 72 bags); CHAOS pixels outside the body mask are excluded. Every map is smoothed with a
  Gaussian before pooling (LACToS: σ in the table below; baselines: each method's published
  composition, i.e. its internal σ = 4 blur followed by σ = 5).
* **LACToS** (paper Table 5; `docs/HYPERPARAMETERS.md` lists every flag):

  | | superpixel size | draws M | histogram σ | bins (intensity × feature) | λ | spatial σ |
  |---|---:|---:|---:|---|---:|---:|
  | CHAOS | 100 | 5 | 0.5 | 16 × 64 | 1 | 2 |
  | FFHQ | 20 | 20 | 1 | 16 × 32 | 0.25 | 5 |
  | DVXray | 10 | 20 | 0 | 16 × 16 | 0 | 5 |

  λ weights the feature term against the intensity term; λ = 0 (DVXray) is the intensity-only score.
* **Baselines** (paper Table 6): PatchCore k = 1; EfficientAD α = 0 / 0.7 / 0.2
  (CHAOS / FFHQ / DVXray); DDAD T = 250, skip 25, η = 1 with (w, v) = (2, 1) / (2, 4) / (4, 4);
  SimpleNet, SuperSimpleNet and GLASS at their defaults.

## Applying LACToS to other images

`evaluate.py` scores one set of 256×256 images. It needs

* the posterior samples and the test image of every sample,
  `<results_dir>/samples_<id>/<origin>_0_4/inpainting/recon/*.png` and `.../label/0_00000.png`
  (`<origin>` is `data.test_origin` in the config; `sampling/` writes this layout),
* the test images `<image_dir>/<id>.png` and binary ground-truth masks `<gt_root>/<id>_mask.png`
  (all-zero for anomaly-free images),
* a config (copy `configs/lactos_ffhq_faces.yaml`),
* for the feature term, an autoencoder checkpoint (`--autoencoder_path`, architecture
  `PixelAutoEncoder` in `evaluate.py`); without one, `--no_pca` gives the intensity-only score.

```bash
python evaluate.py --config configs/my_data.yaml --category mydata --subcategory test \
    --results_dir /path/to/recons --gt_root /path/to/masks --image_dir /path/to/images \
    --no_pca --bins_rgb 16 --smooth_sigma 1 --superpixel_target_size 20 \
    --dump_maps results/my_maps --output_dir results/my_json
python full_metric_table.py --maps_dir results/my_maps --out results/my_metrics.json --sigma 5 --skip_sub
```

The second command smooths the maps with a Gaussian of the given σ and reports the pooled and
per-image metrics.
