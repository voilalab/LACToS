# LACToS

Code for *LACToS: Local Anomaly Detection via Conditional Typicality of Superpixels*
(ICLR 2027 submission).

The repository contains the full pipeline behind the paper's main result table (Table 1):
sampling the diffusion reconstructions, LACToS scoring, the six baselines (PatchCore, SimpleNet,
SuperSimpleNet, EfficientAD, GLASS, DDAD) and the script that builds the table. The table reports
pooled pixel-level **AUROC / AP / AUPRO** on three local-anomaly benchmarks: CHAOS (abdominal CT
with synthetic tumours), FFHQ (faces with prosthetics / atypical features) and DVXray (baggage
X-ray, scissors).

| Dataset | Metric | PatchCore | SimpleNet | SuperSimpleNet | EfficientAD | GLASS | DDAD | **LACToS** |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| CHAOS | AUROC | 0.9297 | 0.7464 | 0.3786 | 0.6664 | 0.8318 | **0.9707** | 0.9620 |
| | AP | 0.0590 | 0.0193 | 0.0051 | 0.0105 | 0.0410 | 0.3159 | **0.4318** |
| | AUPRO | 0.6811 | 0.4191 | 0.0332 | 0.2513 | 0.5530 | 0.8676 | **0.8764** |
| FFHQ | AUROC | 0.8491 | 0.7162 | 0.7647 | 0.6200 | 0.6707 | 0.7469 | **0.8515** |
| | AP | 0.0798 | 0.0537 | 0.0772 | 0.0405 | 0.0345 | 0.0563 | **0.1177** |
| | AUPRO | 0.4094 | 0.3174 | 0.4047 | 0.2365 | 0.2440 | 0.3083 | **0.5320** |
| DVXray | AUROC | **0.9640** | 0.9234 | 0.8688 | 0.9184 | 0.8944 | 0.8567 | 0.9607 |
| | AP | 0.0545 | 0.0254 | 0.0165 | 0.0235 | 0.0155 | 0.0118 | **0.0568** |
| | AUPRO | 0.8141 | 0.6577 | 0.5351 | 0.6592 | 0.6062 | 0.5183 | **0.8179** |

Every one of these 63 numbers is regenerated by the scripts below from the reconstructions,
checkpoints and test data of the asset bundle; `scripts/40_make_table1.py` prints a cell-by-cell
diff against `expected/table1.json`. `docs/REPRODUCIBILITY.md` records the verification runs.

## Setup

```bash
git clone https://github.com/voilalab/LACToS.git && cd LACToS
tar xf /path/to/LACToS_table1_assets.tar            # -> LACToS_table1_assets/
ln -s $PWD/../LACToS_table1_assets assets           # or: export ASSETS=/path/to/LACToS_table1_assets

conda create -n lactos python=3.10 && conda activate lactos
pip install torch==2.0.1 torchvision==0.15.2 --index-url https://download.pytorch.org/whl/cu118   # the reference build
pip install -r requirements.txt                     # numpy, scipy, scikit-image, scikit-learn, pillow, pyyaml, omegaconf, kornia, tqdm
bash scripts/00_check_assets.sh                     # verifies every file against SHA256SUMS
```

The exact environments the numbers were produced with are exported in `environment/`
(`ddad.txt` is the LACToS / EfficientAD / DDAD environment; the baselines need three more, see stage 3).

## Running the pipeline

| Stage | Script | What it does | Needs |
|---|---|---|---|
| 0 | `scripts/00_check_assets.sh` | checks the bundle (layout, counts, SHA-256) | bundle |
| 1 | `scripts/10_sample_{ct,xray,ffhq}.sh` | samples the DPS reconstructions (already in the bundle as `recons/`) | diffusion priors, test images |
| 1b | `scripts/15_pack_bundle.sh` | packs sampled reconstructions into a bundle for upload | stage 1 |
| 2 | `scripts/20_score_lactos.sh` | LACToS scoring at the paper's operating points → per-image delta maps | recons, AEs |
| 3 | `scripts/30_run_baselines.sh` | the six baselines at the paper's settings → per-image raw maps | baseline ckpts, 4 envs |
| 4 | `scripts/40_make_table1.py` | pool, blur, metrics; writes `results/table1.{json,md,tex}` and diffs against the paper | stages 2+3 |

With the bundle, stages 2–4 reproduce every cell (stage 1 can be skipped, its output is `recons/`):

```bash
GPU=0 bash scripts/20_score_lactos.sh                 # or one benchmark: CT | xray | ffhq
GPU=0 bash scripts/30_run_baselines.sh                # or one benchmark: ffhq | ct | xray
python scripts/40_make_table1.py                      # --only lactos | --only baselines
```

### Stage 1: sampling the reconstructions

These commands produce the reconstructions that stage 2 scores, i.e. the `recons/` folder of the
bundle. They need only `checkpoints/diffusion/` and `data/` from the bundle. Each script runs one
process per listed GPU and resumes where it stopped.

```bash
GPUS="0 1 2 3" bash scripts/10_sample_ct.sh       # CHAOS   200 slices x  5 draws = 1,000 reconstructions
GPUS="0 1 2 3" bash scripts/10_sample_xray.sh     # DVXray  144 images x 20 draws = 2,880 reconstructions
GPUS="0 1 2 3" bash scripts/10_sample_ffhq.sh     # FFHQ    100 faces  x 20 seeds = 2,000 reconstructions
#  -> results/recons_mine/results_patches_*/      same directory names and layout as recons/ in the bundle
```

Then either score them in place, or pack them into a bundle (the directory that is archived and
uploaded):

```bash
# score in place (a separate OUT keeps the results of the bundled reconstructions untouched)
OUT=results_mine RECON_ROOT=results/recons_mine GPU=0 bash scripts/20_score_lactos.sh
OUT=results_mine python scripts/40_make_table1.py --only lactos

# pack: checkpoints/ + data/ from the current bundle, recons/ from results/recons_mine, new SHA256SUMS
bash scripts/15_pack_bundle.sh /path/to/LACToS_table1_assets_new
tar -cf LACToS_table1_assets_new.tar -C /path/to LACToS_table1_assets_new
```

Sampler settings and output layout: `sampling/README.md`.

Stage 3 needs the official implementations of PatchCore, SimpleNet, GLASS and SuperSimpleNet
(`bash scripts/fetch_third_party.sh` clones them at the commits we used) and their environments
(`environment/patchcore.txt`, `simplenet.txt` — also used for GLASS —, `ssn_env.txt`; DDAD and
EfficientAD run in the LACToS environment). DDAD and EfficientAD run in the
interpreter that runs the script (your `lactos` env); point the script at the other three with
`PY_PATCHCORE=... PY_SIMPLENET=... PY_SSN=...` or `CONDA_ENVS=/path/to/conda/envs` (the env names
`patchcore`, `simplenet`, `ssn_env`).

All scripts take `GPU=<index>`, `OUT=<results dir>` and `ASSETS=<bundle dir>`; the stage-1 scripts
also take `GPUS="<i> <j> ..."`. Stages 2 and 3 can run in parallel on different GPUs, one benchmark
per GPU. Outputs:

```
results/recons_mine/results_patches_*/                       stage 1: reconstructions (PNG), bundle layout
results/lactos_maps/<bench>/<tag>/<set>/samples_<id>.npz     stage 2: delta_map, gt_mask, valid_mask per image
results/baseline_maps/<bench>/<method>/<setting>/<set>__<id>.npz   stage 3: raw quantities per image
results/table1.{json,md,tex}                                  stage 4
```

## How the numbers are computed

* **Metrics** (`full_metric_table.py`, used identically for every method): all valid pixels
  of all test images of a benchmark are pooled; AUROC and AP over that pool; AUPRO is the
  area under the per-region-overlap curve up to FPR 0.3, normalised by 0.3. Anomalous and
  anomaly-free images are pooled together (CHAOS 100 + 100 slices, FFHQ 50 + 50 faces, DVXray
  72 + 72 bags); CHAOS pixels outside the body mask are excluded. Every map is smoothed with a
  Gaussian before pooling (LACToS: σ in the table below; baselines: each method's published
  composition, i.e. its internal σ = 4 blur followed by σ = 5).
* **LACToS operating points** (paper Table 5; `docs/HYPERPARAMETERS.md` has every flag):

  | | superpixel size | draws M | histogram σ | bins (intensity × feature) | λ | spatial σ |
  |---|---:|---:|---:|---|---:|---:|
  | CHAOS | 100 | 5 | 0.5 | 16 × 64 | 1 | 2 |
  | FFHQ | 20 | 20 | 1 | 16 × 32 | 0.25 | 5 |
  | DVXray | 10 | 20 | 0 | 16 × 16 | 0 | 5 |

  λ weights the feature-typicality term against the intensity term; λ = 0.25 (FFHQ) is composed
  in stage 4 from a full and an intensity-only run of stage 2, λ = 0 (DVXray) is the
  intensity-only run.
* **Baseline settings** (paper Table 6): PatchCore k = 1; EfficientAD α = 0 / 0.7 / 0.2
  (CHAOS / FFHQ / DVXray); DDAD T = 250, skip 25, η = 1 with (w, v) = (2, 1) / (2, 4) / (4, 4);
  SimpleNet, SuperSimpleNet and GLASS at their defaults.

```
scripts/            00_check_assets.sh  10_sample_*.sh  15_pack_bundle.sh  20_score_lactos.sh  30_run_baselines.sh  40_make_table1.py  fetch_third_party.sh

full_metric_table.py  pooled metrics (AUROC, AP, AUPRO, ...)
configs/            evaluate.py configs per dataset; configs/recon/ = FFHQ sampler configs
sampling/           DPS samplers: sampling/dps (CHAOS, DVXray: guided-diffusion + sample_fast.py), generate_recons.py (FFHQ), wire_recons.py

environment/        pip freeze of the four environments
tools/              check_bundle.py (stage 0), seeded_run.py (seeds every stage-2 run)
```
